# Быстрый старт

## Требования

- **Node.js** (актуальная LTS) и **npm**.
- Доступный бэкенд (URL задаётся через `VITE_API_URL`).

## Установка и запуск

```bash
npm install
npm run dev
```

Dev-сервер Vite запустится и автоматически откроет браузер.
Запросы на `/api/v1` проксируются на `VITE_API_URL` (см. `vite.config.ts`).

## Переменные окружения

Приложение использует Vite-переменные (префикс `VITE_` обязателен — иначе
переменная не попадёт в клиентский бандл).

| Переменная     | Назначение                              | Где используется                                                                                                       |
| -------------- | --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `VITE_API_URL` | Базовый URL бэкенда (включая `/api/v1`) | `src/shared/api/client/api-client.ts`, `vite.config.ts` (прокси), refresh-запрос в `src/app/api/setup-interceptors.ts` |

Файлы `.env`, `.env.development`, `.env.production` находятся в `.gitignore`
и **не коммитятся**. Пример `.env.development`:

```env
VITE_API_URL=https://example.com/api/v1
```

> ⚠️ Никогда не коммить реальные `.env` и ключи в репозиторий.

## Команды

| Команда                | Назначение                                            |
| ---------------------- | ----------------------------------------------------- |
| `npm run dev`          | Dev-сервер Vite с открытием браузера                  |
| `npm run build`        | Production-сборка (`tsc -b` + `vite build`) в `dist/` |
| `npm run preview`      | Локальный предпросмотр production-бандла              |
| `npm run lint`         | ESLint по всему проекту (включая FSD-границы)         |
| `npm run format`       | Prettier: отформатировать все файлы                   |
| `npm run format:check` | Prettier: только проверка форматирования              |
| `npm run test`         | Vitest (watch-режим)                                  |
| `npm run prepare`      | Установка Husky-хуков (выполняется при `npm install`) |

## Проверка перед коммитом

Pre-commit хук Husky запускает `npm run lint`. Минимальный ритуал:

```bash
npm run lint
npm run build
```
