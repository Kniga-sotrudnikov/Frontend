# Документация проекта «Книга сотрудников» (Frontend)

SPA на React + Vite + TypeScript для просмотра и редактирования сотрудников,
организационной структуры, вакансий, избранного, проектов и настроек.
Архитектура — [Feature-Sliced Design](https://feature-sliced.design/).

## Содержание

- [Быстрый старт](getting-started.md) — требования, установка, запуск, переменные окружения, команды.
- [Архитектура (FSD)](architecture.md) — слои, правила импортов, структура `src/`, алиасы, соглашения.
- [Маршрутизация](routing.md) — карта маршрутов, защищённые/гостевые роуты, как добавить страницу.
- [Аутентификация](authentication.md) — JWT access/refresh, перехватчики Axios, хранение сессии, роли.
- [Работа с API](api.md) — HTTP-клиент, обработка ошибок, эндпоинты, добавление новых запросов.
- [Управление состоянием](state-management.md) — TanStack Query и Zustand, существующие сторы.
- [Стили и UI-kit](styling.md) — Tailwind CSS 4, тема, шрифты, компоненты `shared/ui`.
- [Качество кода](code-quality.md) — ESLint, Prettier, Husky, тесты.
- [Сборка и деплой](deployment.md) — production-сборка, CI/CD, секреты GitHub.

## Для кого эта документация

Для разработчиков, которые присоединяются к проекту или поддерживают его.
Для AI-агентов есть отдельный файл [AGENTS.md](../AGENTS.md) с правилами работы в репозитории.
