# Маршрутизация

Маршрутизация на `react-router` v7 (data API, `createBrowserRouter`).
Роутер: `src/app/routes/router.tsx`. Константы путей: `src/shared/model/routes/routes.ts`.

## Карта маршрутов

| Путь             | Страница                                 | Доступ                      |
| ---------------- | ---------------------------------------- | --------------------------- |
| `/`              | редирект на `/employees`                 | только авторизованные       |
| `/employees`     | список сотрудников, вакансий, избранного | только авторизованные       |
| `/org-structure` | организационная структура                | только авторизованные       |
| `/projects`      | проекты                                  | только авторизованные       |
| `/settings`      | настройки                                | только авторизованные       |
| `/help`          | помощь                                   | только авторизованные       |
| `/login`         | вход                                     | только **не**авторизованные |
| `/magic-login`   | вход по магической ссылке                | публичный                   |
| `*`              | 404                                      | публичный                   |

## Обёртки доступа

- `ProtectedRoute` (`src/app/routes/protected-route.tsx`) — пускает только
  авторизованных; остальных отправляет на `/login`.
- `GuestOnlyRoute` (`src/app/routes/guest-only-route.tsx`) — пускает только
  неавторизованных (используется для `/login`).

Все защищённые страницы рендерятся внутри `App` (`src/app/app.tsx`) — общего
layout приложения. Страницы подключаются через `lazy()` и экспортируются
из слайса как `Component`.

## Типизация параметров

`src/shared/model/routes/routes.ts` через `declare module "react-router"`
регистрирует `PathParams`, чтобы `useParams()` знал типы параметров текущего
маршрута. Для пути с параметром (`/name/:id`) нужно добавить соответствующую
запись в `PathParams` (в файле есть закомментированный пример).

## Как добавить новую страницу

1. Создать слайс в `src/pages/<name>/` с компонентом, экспортируемым как `Component`.
2. Добавить константу пути в `ROUTES` в `src/shared/model/routes/routes.ts`
   (при наличии параметров — запись в `PathParams`).
3. Зарегистрировать маршрут в `src/app/routes/router.tsx` внутри нужной
   обёртки (`ProtectedRoute` / `GuestOnlyRoute` / публично) через `lazy()`.
4. При необходимости добавить ссылку в навигацию (`widgets/sidebar` / `widgets/navbar`).
5. Проверить `npm run lint` и `npm run build`.
